## How to run tests
```bash
cd tests/smoke
npm install
npx playwright install chromium   # or: SMOKE_CHROME=/usr/bin/google-chrome npm test
npm test                          # serves the repo root on 127.0.0.1:4173 and runs smoke.spec.mjs
```
- Checks: Home loads; Nests nav + `+` visible; no `Dummy feed` text; `noindex` present unless the room is lifted (`site.json preview: false`, or `SMOKE_LIFTED=1`).
- Read-only: no sign-in, no writes. Cloud Functions, the visit pixel and analytics are blocked in the test.
- `SMOKE_BASE_URL=https://example.test npm test` runs it against a running copy instead of a local server.
- CI: `.github/workflows/smoke.yml` runs on every pull request (free GitHub Actions minutes on this public repo). A PR must be green before Jebb merges.
